# UX do RecolheTudo

## Quem e o usuario

O usuario principal e o catador de materiais reciclaveis que trabalha em movimento, com pouca disponibilidade para preencher formularios longos e nem sempre com conexao a internet.

Esse usuario precisa:

- registrar coletas rapidamente
- confiar que os dados vao ficar salvos
- entender o proprio desempenho com poucos elementos visuais
- saber quando o app esta funcionando offline

## Problema que o app resolve

Sem uma ferramenta simples, o trabalho fica espalhado em memoria, papel ou anotações soltas. Isso dificulta:

- acompanhar produtividade
- revisar historico de coletas
- manter consistencia de registro
- usar rotas de forma organizada

O RecolheTudo reduz essa friccao com um fluxo de uso direto e visual.

## Fluxo principal

1. O usuario abre a Home e entende rapidamente o estado do dia.
2. O usuario toca em "Registrar nova coleta".
3. Escolhe o material.
4. Define o peso.
5. Confere o resumo e salva.
6. A coleta fica salva no aparelho, mesmo sem internet.
7. Depois o usuario consulta o Historico, Rotas ou Perfil.

## Decisoes de interface

### Direcao visual

- verde escuro como base de marca e sustentabilidade
- cards brancos grandes para leitura facil
- botoes principais cheios e bem destacados
- chips de material com leitura direta
- espacos amplos para evitar poluicao visual

### Linguagem

A interface evita termos tecnicos e prioriza frases de produto:

- "Dados salvos no aparelho"
- "Funciona sem internet"
- "Coleta salva com sucesso"
- "Sincronizacao pendente"
- "Localizacao capturada"

### Home

- hero principal com promessa de valor
- CTA claro para nova coleta
- resumo rapido do dia
- distribuicao por material
- acoes rapidas para navegacao

### Coleta

- fluxo guiado em tres etapas
- selecao de material visivel
- peso em destaque
- confirmacao antes de salvar
- linguagem objetiva para evitar erro

### Historico

- filtros por periodo e material
- metricas resumidas no topo
- lista agrupada por data
- cada item com peso, horario e status de localizacao

### Rotas

- card principal de rota sugerida
- metricas de pontos, distancia e tempo
- lista sequencial de pontos
- CTA para iniciar rota

### Perfil

- meta diaria em destaque
- ritmo semanal com grafico simples
- status offline em linguagem humana
- reforco de confianca no salvamento local

## Melhorias futuras

- modo escuro opcional
- avatar e identidade do trabalhador configuraveis
- feedback visual de sincronizacao em tempo real
- historico com edicao de coletas
- rotas com agrupamento por bairro ou area
- acessibilidade reforcada para texto, contraste e toque
